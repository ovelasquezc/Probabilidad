## Organización del curso

Cada semana comprende dos sesiones de teoría y una sesión práctica. Las notas incluyen las demostraciones desarrolladas en el curso y, cuando corresponde, anexos para argumentos técnicos que no se completan en la pizarra.

Las listas distinguen los ejercicios previstos para el aula, el trabajo autónomo y las ampliaciones voluntarias. Las evaluaciones y sus soluciones se publicarán únicamente cuando corresponda.

## Convenciones

- Se usa \(F_X(x)=\mathbb P(X\le x)\) para la función de distribución.
- La teoría de la medida se emplea como prerrequisito y se recuerda cuando es necesaria.
- Las hipótesis forman parte de los enunciados y de las demostraciones.

## Bibliografía principal

- Rick Durrett, *Probability: Theory and Examples*, edición 4.1.
- Gilbert Saporta, *Probabilités, analyse des données et statistique*, segunda edición, selección de los capítulos 1–4.
- MIT OpenCourseWare, 18.175 *Theory of Probability*, primavera de 2014, selección de notas y problemas.

Los libros y materiales originales no se redistribuyen en este repositorio. Las separatas son una elaboración para CM4H1 y no una traducción literal de las fuentes.
